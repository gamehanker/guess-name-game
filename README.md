# guess-name-game
# 猜人名活動

一個簡單的網頁版猜人名遊戲，適合系上活動、迎新、破冰活動或聚會使用。

## 功能

* 一次匯入多張人物圖片
* 自動將圖片檔名作為答案
* 隨機排列題目順序
* 顯示／隱藏答案
* 上一題／下一題
* 可手動修改答案
* 支援全螢幕模式
* 支援鍵盤快捷鍵

## 使用方式

1. 先將圖片檔名改成人名，例如：

```text
陳柏諺.jpg
王小明.png
李小華.jpeg
```

2. 開啟網頁。
3. 點擊「選擇圖片」。
4. 一次選擇所有要使用的照片。
5. 系統會自動隨機排列圖片。
6. 顯示照片後讓參加者猜人名。
7. 按「顯示答案」公布答案。

## 快捷鍵

| 按鍵    | 功能      |
| ----- | ------- |
| ←     | 上一題     |
| →     | 下一題     |
| Space | 顯示／隱藏答案 |
| F     | 全螢幕     |
| R     | 重新洗牌    |

## GitHub Pages

本專案可以直接透過 GitHub Pages 使用。

在 Repository 中進入：

```text
Settings
→ Pages
→ Deploy from a branch
→ main
→ /(root)
```

設定完成後即可透過 GitHub Pages 網址開啟遊戲。

## 隱私說明

使用者選擇的圖片只會由瀏覽器在本機讀取，不會自動上傳至伺服器或 GitHub。
